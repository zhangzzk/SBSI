# Separate primary and neighbour shear on the original fields

## Sampling and four corners

Run the operational pilot in the [original design](../primary_neighbour_grid_20261106/design.md#proposed-operational-pilot-and-scaling-rule): exactly 256 distinct primaries from each of the union-of-two-coherent-detections and complementary rendered-truth strata, per case 1000, 1040, 1080, 1120. Uniform sampling without replacement, PCG64(seed=202611070700+case), sorted IDs within each frame, no size/magnitude or success preselection. Retain inclusion probabilities, stratum order and inverse-probability weights. Use g1=±0.02; g2=0. This measures R11 and R21, not R22. No new noise is drawn.

Use a full-size copy of the source exposure as the isolated scene for each target. This is costlier than placing cutouts on a grid but preserves the original detector background, neighbours, pixel subphase and SExtractor context. Exactly one source changes in any mixed exposure. With original noisy coherent images I++ and I-- and renderer-native single-primary light difference d=P+−P-, form I+-=I--+d and I-+=I++−d. Faint neighbours, bright wings, PSF and noise remain in the original image; no neighbour truncation or coherent selection is imposed on mixed legs. Float64 differences of native float32 primary stamps are applied and written once at native image precision. Restore original pixels before changing the next primary. Never write to the source exposures.

## Gates and cost

- Pin original input/measurement catalogues, PSF/noisy images and sampling receipts. Require unique identities and equal rendered truth across coherent legs, except for the shear column.
- Independently reconstruct **both** old A/B-split minus coherent pixel differences from the actual sign assignments, original PSF and renderer, for the first four draws per stratum per case (32 sky patches, two contrasts each). Measure in the central 65-pixel stamp; require patch RMS < 0.0001 sky RMS and maximum < 0.005 sky RMS, with a detectable signal. The 96/192-pixel first check failed for one patch. Extend the surrounding-source search to 384, 768, then 1536 pixels as needed, without changing tolerance. These guards only validate the renderer; all mixed interventions use the original full field and complete primary stamp. Check the primary stamp reaches zero at every artificial edge, or enlarge it.
- Rerun native SExtractor on all eight original full exposures, requiring **byte-identical ASCII catalogues**. Check one-to-one truth matches for all 4096 coherent primary/leg rows against original assignments. For efficient matching, use the connected component of the original 2.5-pixel bipartite graph, original full-catalogue tangent point, four choices, magnitude duplicate rule and original row ordering. Require a closed component inside the retained window. Undetected primaries stay in the sampling frame. Compare coherent, mixed and source fits at the correct per-leg centroid using the original centred 65-pixel one-Gaussian fitter and two predeclared optimizer seeds shared across corners (SeedSequence keyed by 202611070701, case, ID, repeat). The seeded coherent fits are the control for the mixed fits; earlier entropy-seeded catalogue fits are not expected to replay exactly.
- First run one primary in each stratum in all four scenes and both mixed corners (16 full-size detector calls). Predeclared operational release for the fixed 2048-primary pilot: the controls pass and 4096 exposures at the slowest trial runtime project below 400 CPU hours of extraction. The tiny operational subset is not an estimate of bias. Pack remaining exposures into long-lived allocations with per-primary receipts; do not scale the primary count on this result.
- No changes to the classifier, emulator, flows or selection, and no model choice. Run the three fixed neighbour-conditioned source endpoints (initial, nine-cut, nine-cut plus neighbour moment). Reuse the original 1024-parent chunks and 64 portable antithetic draws, seeds, pairs, and ancillary features. Coherent generated-selection, predicted-usability responses must reproduce the previous full-scene results to the existing 1e-6 response tolerance. The primary shear sets the flow and classifier input; the neighbour shear sets the sign of the disk velocity. Use actual per-corner flags for flag interventions; measured-selection diagnostics do not replace generated emulator photometry.

## Estimator and limits

For each corner separately, divide the weighted selected ellipticity sum by its own weighted selected mass, pooling case/stratum sums. Apply radius > 2.8, 3.0, 3.2 pixels crossed with magnitude < 24.9, 25.0, 25.1. As in the [original four-corner design](../primary_neighbour_grid_20261106/design.md#four-shear-corners-and-exact-closure), primary and neighbour finite contrasts add to coherent response; this identity alone cannot certify the image intervention. Use the [project response convention](../../CONVENTIONS.md#6-response-estimators) and simulation-minus-model signs. Compare the two optimizer repeats, primary-sampling and scene uncertainty separately. This is a precision pilot on reused scenes. Do not promote a checkpoint, treat a nonsignificant error as zero, or launch a larger campaign from its central value.
