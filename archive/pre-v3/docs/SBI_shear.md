# Unified Differentiable Emulator for Shear Biases

> **Current framing lives in [`INFERENCE.md`](INFERENCE.md)** — the joint
> measurement+detection flow, the product-rule response decomposition, and the data/cut
> rules. This document is the deeper background; where the two differ, `INFERENCE.md` wins.
> (Supersedes the retired `GOALS.md`, locked 2026-07-22.)

A research plan for a learned, autograd-based framework that jointly handles selection bias, measurement bias, and blending response (including redshift-mixing) by learning the conditional density of catalogue entries as a function of true shear.

---

## 1. Motivation and scope

### The idea

Train neural models on image-simulation outputs to learn the conditional catalogue-entry density for measured properties $\hat{\mathbf{x}}$ conditioned on true galaxy properties and neighbour properties — **with no shear argument**:

$$p_\text{cat}(\hat{\mathbf{x}} \mid \mathbf{x}, \mathbf{n})$$

Here $p_\text{cat}$ means "the probability density to see a selected catalogue object with measured properties $\hat{\mathbf{x}}$." It is not normalized to one over $\hat{\mathbf{x}}$; it integrates to the selection probability.

Shear is applied to the *true scene* before rendering, so it does not need to be a model input: the model is trained on a single $g=0$ realization, and $\gamma$ enters only through the known analytic distortion $S_\gamma$ of the true properties (§2). This gives two outputs:

- **Inference:** $\gamma$ recovered from a shear-free forward model via a BFD-family marginal likelihood, where shear shifts the true-property prior through $S_{-\gamma}$.
- **Response:** $\partial P(s=1)/\partial\gamma$ (selection) and $\partial\langle\hat{\mathbf{x}}\rangle/\partial\gamma$ (measurement) by autograd through $S_\gamma$, including redshift-aware blending response via explicit neighbour conditioning.

### Honest framing

| Aspect | Assessment |
|--------|-----------|
| Unified shear calibration framework | **Primary goal** — one differentiable model for selection, measurement, and blending responses |
| Replacing standard shear calibration at $m < 2 \times 10^{-3}$ | Ambitious; AnaCal is a strong benchmark in the standard regime |
| Beating AnaCal in every standard metric | Not required for the core contribution; benchmark honestly |
| Redshift-aware blending response | **Key differentiator** — explicit neighbour-redshift conditioning is not available in standard calibration methods |
| Methodological contribution | Real: unified differentiable framework with neighbour conditioning |

**Recommended paper framing:** Unified differentiable shear-calibration emulator that jointly models selection, measurement, and blending responses. Redshift-aware blending response is the main distinguishing capability; competitive performance in the standard regime is an important validation target.

## 2. Mathematical framework

### Quantities

- $\gamma$ — true shear
- $\mathbf{x}$ — true galaxy properties (flux, size, shape, redshift, ...)
- $\mathbf{n}$ — neighbour true properties (including redshift)
- $\hat{\mathbf{x}}$ — measured/catalogue properties
- $s \in \{0, 1\}$ — general selection indicator: detection, measurement success, catalogue cuts, and any analysis selection

### Coordinate convention

Use one spin-2 coordinate convention for every orientation-dependent quantity.
In SBSI, the canonical sky basis is

$$
(q_1, q_2) = q(\cos 2\theta, \sin 2\theta).
$$

This convention applies to:

- intrinsic ellipticity: $(e_1,e_2)$
- the spin-2 basis generated by relative pair angle:
  $(\cos 2\phi,\sin 2\phi)$
- canonical shear features: $(\gamma_{1,\mathrm{sky}},
  \gamma_{2,\mathrm{sky}})$
- pair-aligned projections such as $e_\parallel,e_\times$ and
  $\gamma_\parallel,\gamma_\times$

Blendemu catalogues store applied shear in this same usual basis and should
carry `shear_component_convention = "sky_cos_sin"` in newly generated
catalogues. If the metadata is absent, SBSI still interprets
`gamma1_input/gamma2_input` as sky-basis components.

### Shear as a distortion of the true scene

Shear is not an extra label that the rendering "knows about" separately from the
galaxies. In the simulator it is applied to the *true scene before rendering*: it
distorts each galaxy's intrinsic shape, shears the relative geometry of neighbouring
objects, and (de)magnifies fluxes and sizes; the PSF and pixel noise are applied
afterward and do not depend on $\gamma$. Define the analytic, closed-form,
differentiable shear map $S_\gamma$ acting on the true scene $(\mathbf{x}, \mathbf{n})$:

- **Shape** — reduced-shear Möbius transform, complex $e = e_1 + i e_2$,
  $g = \gamma_1 + i\gamma_2$:
  $$e' = \frac{e + g}{1 + g^{*} e}$$
- **Relative geometry** — separation vector to each neighbour:
  $$\Delta\boldsymbol\theta' = (I - \Gamma)\,\Delta\boldsymbol\theta,
  \qquad \Gamma = \begin{pmatrix} \gamma_1 & \gamma_2 \\ \gamma_2 & -\gamma_1 \end{pmatrix}$$
- **Magnification** of flux and size by
  $\mu = \left[(1-\kappa)^2 - |\gamma|^2\right]^{-1}$, to the extent the image
  simulation applies it (for pure shear, $\kappa=0$, this is a second-order effect).

$S_\gamma$ is built entirely from quantities the catalogue already stores separately —
intrinsic shape `e*_input_rot0` and applied shear `gamma*_input` — so the post-shear
true scene is a deterministic function of stored truth, not something that must be
learned.

**Where $S_\gamma$ is actually used.** Only its *derivative at $\gamma=0$* enters the
science: that derivative is the responsivity that converts an inferred true shape into a
shear (below), and it is computed from the prior, not applied to data. The *full
nonlinear map* is needed only for (i) exact finite-shear inference — the prior shift
below — and (ii) validation: analytically injecting shear into $g=0$ scenes for held-out
recovery or finite-difference gradient checks (§6). It is never applied to the measured
data.

> **Convention / scope check.** The shape Möbius transform is certain: it is the spin-2
> shear the generator applies in the `sky_cos_sin` basis (`blendemu/catalog.py`,
> consistent with `e2ang`/`spin2rot` in `response.py`). The precise handling of
> separation shearing and magnification lives in MultiBand_ImSim and must be pinned
> against the generator before the inference code is written, together with a per-column
> ledger of which stored truth quantities are intrinsic (need $S_\gamma$ applied) versus
> already post-shear (e.g. `distance` derived from detected positions).

### Sufficiency: the learned density is shear-free

Because the measured image — hence detection and every measured property — is a
stochastic function of the *post-shear true scene alone* (PSF and noise fixed and
shear-independent), the catalogue density obeys a sufficiency relation:

$$p_\text{cat}(\hat{\mathbf{x}} \mid \mathbf{x}, \mathbf{n}, \gamma)
= p_\text{cat}\big(\hat{\mathbf{x}} \mid S_\gamma(\mathbf{x}), S_\gamma(\mathbf{n})\big).$$

At fixed post-shear true scene, $\hat{\mathbf{x}} \perp \gamma$. The central object is
therefore an *unnormalized selected-catalogue density conditioned on true properties
only*, with no explicit shear argument:

$$p_\text{cat}(\hat{\mathbf{x}} \mid \mathbf{x}, \mathbf{n})
\equiv p(\hat{\mathbf{x}}, s=1 \mid \mathbf{x}, \mathbf{n})
= p_\text{meas}(\hat{\mathbf{x}} \mid \mathbf{x}, \mathbf{n}, s=1)
\, P(s=1 \mid \mathbf{x}, \mathbf{n}).$$

This keeps the honest reading: $\hat{\mathbf{x}}$ is not drawn from a normalized
distribution; the density integrates to the selection probability,

$$\int p_\text{cat}(\hat{\mathbf{x}} \mid \mathbf{x}, \mathbf{n})\,d\hat{\mathbf{x}}
= P(s=1 \mid \mathbf{x}, \mathbf{n}).$$

**Practical consequence — train at $g=0$ only.** A single unsheared realization already
spans the full range of intrinsic shapes, sizes, and separations, so the forward map
$p_\text{cat}(\hat{\mathbf{x}}\mid\mathbf{x},\mathbf{n})$ contains all the responsivity
information. Applied shear is not needed as a training label; the multi-shear catalogue
is reserved for end-to-end validation (§6).

### Trained components (all shear-free, learned at $g=0$)

**Selection model:**
$$P(s = 1 \mid \mathbf{x}, \mathbf{n})$$

The first concrete implementation uses detection as the selection event,
$s=1 \equiv \text{detected by SExtractor}$; later $s$ should include measurement success
and analysis cuts.

**Measurement likelihood for selected objects:**
$$p_\text{meas}(\hat{\mathbf{x}} \mid \mathbf{x}, \mathbf{n}, s=1)$$

**Intrinsic true-property prior** $p_0(\mathbf{x}, \mathbf{n})$ — the one place shear
enters (below), and the one factor that should come from external deep fields rather than
$p_\text{sim}$.

### Shear enters only through the prior

Because the learned pieces are shear-free, $\gamma$ appears in exactly one place: it
shifts the intrinsic true-property distribution through $S_\gamma$. For a set of measured
objects $\{\hat{\mathbf{x}}_i\}$ with neighbour information,

$$p(\gamma \mid \{\hat{\mathbf{x}}_i\})
\propto p(\gamma)\prod_i \int
p_\text{meas}(\hat{\mathbf{x}}_i \mid \mathbf{x}, \mathbf{n}, s=1)\,
P(s=1 \mid \mathbf{x}, \mathbf{n})\,
p_0\!\big(S_{-\gamma}(\mathbf{x}, \mathbf{n})\big)\,
d\mathbf{x}\,d\mathbf{n},$$

up to the appropriate count/selection normalization. The learned likelihood and
selection terms are evaluated at $g=0$; all shear dependence is carried analytically by
the $S_{-\gamma}$ shift of the prior. This is the BFD-family marginal likelihood
(Bernstein & Armstrong 2014) with a *learned, neighbour-conditioned, selection-aware*
forward model in place of an analytic moment likelihood.

### Per-galaxy inverse posterior and the linearized estimator

For a real galaxy with measured $(\hat{\mathbf{x}}, \mathbf{n})$, invert the shear-free
forward model:

$$p(\mathbf{x} \mid \hat{\mathbf{x}}, \mathbf{n}, s=1)
\propto p_\text{meas}(\hat{\mathbf{x}} \mid \mathbf{x}, \mathbf{n}, s=1)\,
P(s=1 \mid \mathbf{x}, \mathbf{n})\,
p_\text{target}(\mathbf{x} \mid \mathbf{n}).$$

**Critical:** $p_\text{target}$ must come from external deep fields, not $p_\text{sim}$,
to decouple the answer from the simulation population.

The marginal likelihood above is the primary estimator, and the shear **response is
internal to it** — there is no external responsivity to apply afterward. Maximizing (or
sampling) it returns calibrated shear directly; the role usually played by an explicit
responsivity is here just the curvature $\mathcal{L}''(0)$ of the likelihood, supplied
automatically by the same $p_\text{meas}$, $P(s=1)$, and $p_0$.

The familiar point estimate
$$\hat{\gamma} = \frac{\langle e_\text{true}\rangle_\text{pop}}{R}$$
is the weak-shear linearization of this, and it makes the responsivity concrete:
*naively averaging posterior-mean shapes undershoots*. Inverting a sheared population
against the shear-free prior $p_0$ shrinks each $\bar e_i$ toward zero, so
$\langle\bar e\rangle = R\,\langle e_\text{true}\rangle$ with $R<1$; dividing by $R$ (the
prior-shrinkage factor, which $\to 1$ as S/N$\to\infty$) undoes exactly that shrinkage.
The full marginal likelihood applies this self-consistently and never forms the shrunk
point estimate. Either way, once corrected the estimator has unit response by
construction, $d\langle\hat\gamma\rangle/d\gamma = 1$ — there is no residual responsivity
to apply twice. Both routes say the same thing: *shear is inferred from a shear-free
model, never used as a label*.

### Response extraction (differentiable, prior-light cross-check)

The same shear-free model yields responses directly by differentiating through
$S_\gamma$. For a catalogue statistic $O(\hat{\mathbf{x}})$ under a target population
$p_\text{target}(\mathbf{x},\mathbf{n})$,

$$\frac{\partial}{\partial\gamma}\,
\mathbb{E}\big[O(\hat{\mathbf{x}})\big]
= \int O(\hat{\mathbf{x}})\,
\frac{\partial\, p_\text{cat}\big(\hat{\mathbf{x}}\mid S_\gamma(\mathbf{x}),S_\gamma(\mathbf{n})\big)}{\partial\gamma}\,
p_\text{target}\,d\hat{\mathbf{x}}\,d\mathbf{x}\,d\mathbf{n},$$

with $\partial/\partial\gamma = (\partial S_\gamma/\partial\gamma)\cdot\nabla$ obtained by
autograd through the analytic map. The population-level selection response
$\langle\partial P(s=1)/\partial\gamma\rangle$ follows identically. Its dominant channel
is the magnification/size and sheared-separation part of $S_\gamma$, not the shape
Möbius — consistent with the finding that primary size and flux drive the selection
response. Because this response is a property of the learned map evaluated on the
observed sample, it is far less sensitive to the intrinsic-shape prior than the full
inversion, and serves as a metacalibration-style cross-check and bulk-calibration anchor
(see prior dependence below).

### Why the naïve "$\hat e$ estimates $\gamma$" reading is wrong

The shape response decomposes as

$$\frac{\partial \langle \hat e\rangle}{\partial\gamma}
= \underbrace{\frac{\partial \langle \hat e\rangle}{\partial e'}}_{\text{measurement response}}
\cdot
\underbrace{\frac{\partial e'}{\partial\gamma}}_{\text{analytic, } \sim\, 1-|e|^2}.$$

The second factor is the known true-shape responsivity from $S_\gamma$. The first factor
carries noise bias, model bias, PSF, selection, and blending and is generally not unity.
$\hat e$ is an unbiased estimator of $\gamma$ only in the idealized limit where that
factor $\to 1$; the framework correctly collapses to $\langle\hat e\rangle=\gamma$ there,
and the deviations from it are exactly the calibration this emulator exists to capture.

### Prior dependence and the cost of redshift-aware blending

Inferring shear from a forward model makes this method **prior-dependent**, and that
dependence must be owned rather than hidden.

**Why the prior enters.** Shear is degenerate with the intrinsic shape distribution:
$\langle e_\text{obs}\rangle \approx \langle e_\text{int}\rangle + R\gamma$, so one cannot
separate a slightly anisotropic intrinsic population from a small shear without knowing
$p_0(e_\text{int})$. At low S/N the posterior is prior-dominated — the origin of classical
noise bias.

**Two responsivities — only one of them is the prior.** Keep these distinct, or the
prior-dependence argument gets muddled:

- *Measurement / classical responsivity* — $\mathcal{R} = 2(1-e_\text{rms}^2)$ (Bernstein
  & Jarvis 2002): set by the intrinsic shape **dispersion** and the ellipticity
  **convention**, plus PSF dilution and selection in image pipelines. It survives perfect
  measurement, is **prior-free**, vanishes ($\mathcal{R}\to1$) for the reduced-shear
  $\varepsilon$ ellipticity, and is exactly what metacalibration/metadetection *measure
  from the data*.
- *Prior shrinkage* — the extra $R<1$ from inverting a sheared population against the
  shear-free prior $p_0$. This one **is** the prior: it exists *because shear is not in the
  prior* (using the correctly sheared prior gives $R=1$ exactly), and it $\to1$ as
  S/N$\to\infty$.

In our pipeline the convention factor is removed by using $\varepsilon$ and PSF dilution
is absorbed by the forward model, so the *residual* responsivity is the prior-shrinkage
piece — which is why, for us, $R$ is prior-dominated. That is a bookkeeping outcome, not a
universal fact: do **not** carry "responsivity is a prior artifact" into the comparison
with metacalibration, where $R$ is real, prior-free measurement physics that persists at
infinite S/N.

**Two philosophies.**

- *Prior-based / Bayesian* (this method's family): lensfit (Miller et al. 2013; Fenech
  Conti et al. 2017) and BFD (Bernstein & Armstrong 2014) marginalize a per-object
  likelihood over an intrinsic-property prior measured from deeper imaging — rigorous to
  the extent the deep-field prior matches the true population.
- *Response-based / self-calibrating*: metacalibration (Sheldon & Huff 2017) and
  metadetection (Sheldon et al. 2020) shear the *image* and remeasure to read the
  responsivity (and, for metadetection, the detection/selection response) directly off
  the data, with no intrinsic-shape prior. This prior-independence is why they are the
  Stage-IV frontrunners.

**The hard limit of self-calibration — and our opening.** Metadetection shears the whole
postage stamp by a single $\gamma$, so for a blend mixing sources at different redshifts
(hence different true shears) it returns only a redshift-*averaged* response and cannot
resolve the redshift-dependent blending bias that is known to be real (MacCrann et al.
2021/2022, DES Y3). That z-resolved response is intrinsically a forward-model quantity:
it requires knowing or inferring the true properties — including redshift — of the blend
members. **Prior dependence is therefore the price of admission for redshift-aware
blending**, the project's differentiator.

**Mitigations.**

1. **Deep-field prior.** Take $p_\text{target}(\mathbf{x},\mathbf{n})$ from deeper /
   higher-S/N imaging (LSST Deep Drilling Fields; Balrog-style injection), never from
   $p_\text{sim}$.
2. **Prior quarantining.** The learned conditionals $p_\text{meas}$ and $P(s=1)$ are
   prior-free; the prior enters only at the marginalization step, where it is a swappable
   input whose uncertainty can be propagated. The prior is isolated to one
   externally-measurable factor rather than baked into the estimator.
3. **Differentiable response cross-check.** Use the prior-light response route above for
   bulk calibration and as a consistency check on the inversion.
4. **Hierarchical option.** Infer the intrinsic-shape prior jointly with shear
   (population-level hierarchical model) to reduce prior sensitivity, at higher
   computational cost.

## 3. Dimensionality and feasibility

### Parameter count for primary + secondary pair

| Group | Parameters |
|-------|-----------|
| Primary | flux, size, Sersic index, $e_1$, $e_2$ |
| Secondary | flux, size, Sersic index, $e_1$, $e_2$ |
| Geometry | angular separation, relative position angle |
| **Conditioning total** | **12D true properties** |

Shear is **not** a conditioning axis: the forward model is trained at $g=0$ and $\gamma$
is inferred (it enters only as the $S_{-\gamma}$ shift of the prior, §2). The true-scene
properties above are already the post-shear ones at inference time.

### Difficulty assessment

12D is well within modern flow capabilities. Not the bottleneck. The current
implementation also includes engineered flux-ratio and shape-alignment
features, which are deterministic functions of these basic quantities.

**Real difficulty drivers:**

1. **Coverage of the joint distribution** — must densely sample (separation × flux ratio × ellipticity) where blending matters
2. **Smoothness of underlying response** — generally fine; smooth except near selection thresholds
3. **Heavy-tailed distributions** — flux is log-normal-ish, separations have power-law tails; transform inputs to roughly Gaussian before training
4. **Threshold concentration** — $\partial P(s=1)/\partial\gamma$ is concentrated in a thin band of (flux, size) space; classifier can collapse to "always 0" or "always 1" away from it
5. **Binary label noise** — each simulated galaxy gives one bit about $P(s=1)$; need many similar galaxies to resolve the gradient

## 4. Model recommendations

### Selection model

**Calibrated MLP**

- 4-6 hidden layers, ~256-512 units
- GELU or SiLU activations (smoother gradients than ReLU)
- Sigmoid output on a single logit
- Binary cross-entropy as the default loss, because calibrated probabilities
  are the science target
- Focal loss ($\gamma_\text{focal} \approx 2$) remains useful as a diagnostic
  or fallback if threshold/imbalance effects dominate, but it should be checked
  carefully against calibration curves
- **Mandatory:** temperature/Platt scaling on a held-out set after training. Neural classifiers are systematically miscalibrated; gradients of predicted probability are biased even when accuracy is high.

**Alternative:** Sparse Gaussian Process classifier (SVGP) up to ~$10^5$ training points — gives analytic gradient uncertainty.

### Measurement model

**Neural Spline Flow (RQ-NSF)**

- Library: `zuko` (modern, good autograd support) or `nflows`
- Rational-quadratic spline coupling layers, 8-12 layers
- Conditioner: MLP with ~256 units, GELU
- Base: standard Gaussian
- Bins: 8-16 per transform
- **Preprocessing:** log for flux/size, logit for ellipticity moduli, sin/cos for angles

Avoid Mixture Density Networks (mode collapse, bad tail gradients). Skip diffusion models — overkill for 7D smooth densities.

**Current implementation note:** the first SBSI measurement-likelihood workflow
uses a pure PyTorch conditional affine coupling flow because the active `sims1`
environment has PyTorch/PyArrow but no `zuko` or `nflows`. The public interface
follows the shear-free factorization:

$$p_\text{meas}(\hat{\mathbf{x}} \mid \mathbf{x}, \mathbf{n}, s=1)$$

Default conditioning uses the primary-frame selection features plus primary and
gated-neighbour redshift. **Migration note:** the existing selection/measurement
features still pass intrinsic shape and applied shear as *separate* inputs (a legacy of
the γ-conditioned design). Under the refined framework (§2) the model is trained at
$g=0$ and conditions on true (post-shear at inference) scene properties only; the
separate `gamma_pframe_*` inputs should be dropped, with $\gamma$ inferred rather than
conditioned. Default continuous targets are engineered SExtractor
measurements: log flux, log flux radius, log major/minor image axes, and
spin-2 image-shape components from `measured_a_image`, `measured_b_image`, and
`measured_theta_image`. This is a runnable baseline for the joint measured
property density; replacing the flow backend with RQ-NSF remains the preferred
upgrade once the dependency is available.

### Neighbour handling

For pairs (current 11D): plain MLP is fine.

For variable-number neighbours: **Set Transformer with ISAB blocks** if neighbour-neighbour interactions matter; **DeepSets** if neighbours contribute additively.

**Current scene-level baseline:** use one training example per primary scene,
grouped by `(case, shear_case, input_index)`. The neighbour condition is a
ragged set of all annotated neighbours inside the aperture, encoded with a
DeepSets conditioner. The primary branch also receives explicit summary
features: neighbour count, nearest scaled distance, brightest-neighbour flux
ratio, and total neighbour-to-primary flux ratio. This is the preferred path
for the measurement likelihood once the detection-measurement catalogue has
been built with sufficiently large `k` to cover the full aperture.

The scene trainer supports two geometry modes:

- `full`: per-neighbour distance, pair angle, oriented neighbour shape, and
  neighbour shear features.
- `radial`: per-neighbour distance plus scalar properties only: size, flux
  ratio, Sersic index, ellipticity amplitude, and redshift.

The radial mode is an explicit angle-marginalized ablation for ensemble-level
calibration. It should be compared to the full-geometry model with held-out NLL
and finite-difference measurement-response diagnostics before being used as a
science approximation.

### True-property prior

Three options:

| Option | Use when |
|--------|----------|
| (a) Train a third RQ-NSF for $p_\text{sim}$ | Clean, but adds a model |
| (b) Use empirical simulation distribution | Default; requires importance reweighting |
| (c) Skip and use external $p_\text{target}$ | **Recommended for population-level $n_\gamma(z)$** |

## 5. Training strategy

### Stratified sampling (critical)

Selection-threshold objects dominate the gradient signal. Oversample:

- Faint, small, high blend contamination galaxies
- Close pairs
- Extreme flux ratios

Weight loss by inverse sampling probability to recover unbiased estimates.

### Multi-shear training

Train on $\gamma \in \{-0.1, -0.05, -0.02, 0, 0.02, 0.05, 0.1\}$ (or similar) rather than just $\{0, 0.1\}$:

- Verifies linearity directly
- Smoother gradient targets
- Reduces extrapolation error at $\gamma=0$
- **Also:** $\gamma=0.1$ alone is large; risk of nonlinearity in selection response

### Antithetic pairs (ring tests)

Within each $\gamma$, pair galaxies with intrinsic $(e_1, e_2)$ and $(-e_1, -e_2)$. Suppresses shape noise in the response estimate. Standard in image-simulation calibration.

### Staged training

Train the selection model first to convergence, then freeze and train the measurement model conditional on $s=1$. Joint training adds optimization complexity without obvious gains.

## 6. Validation (non-negotiable)

### Held-out-shear recovery (primary, end-to-end)

Because the forward model is trained at $g=0$, the multi-shear catalogue becomes a clean
end-to-end test rather than training data:

1. Train $p_\text{meas}$ and $P(s=1)$ on the $g=0$ realization only.
2. Apply the estimator (marginal likelihood, or $\hat\gamma=\langle e_\text{true}\rangle/R$)
   to the held-out $g=0.05$ and $g=0.1$ realizations.
3. Require recovery of the input shear, $\hat\gamma \approx \gamma_\text{true}$, to within
   Monte Carlo noise.

This simultaneously tests the sufficiency assumption (§2), the $S_\gamma$ map, and the
prior/responsivity treatment — a stronger statement than any single-component check.

### Finite-difference vs autograd (component check)

The differentiable response route must also pass a local gradient check:

1. Build a test set with multiple $\gamma$ values per galaxy configuration via $S_\gamma$.
2. Compute finite differences $\Delta P(s=1) / \Delta \gamma$.
3. Compare against autograd $\partial P / \partial \gamma$ through the trained model and
   the analytic map.
4. They must agree to within Monte Carlo noise.

If they disagree, the derivative estimate is biased even if the classifier looks "good."
This is what separates a working pipeline from a paper that gets challenged at review.

**Key differentiator:** redshift-aware blending response via explicit conditioning on
neighbour redshift, within a unified shear-calibration framework. The trade-off is
explicit: this is the only entry that resolves redshift-mixing in blends, and the only
one that pays for it with prior dependence — a forward-model quantity that image-level
self-calibration (metadetection, AnaCal) structurally cannot deliver (§2, prior
