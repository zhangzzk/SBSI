# When does shear change which galaxies pass?

## Which shear the model can see

For one chosen target, the evaluator builds two copies of the same truth frame and [replaces only the first two columns with that target's sheared ellipticity](../../../archive/research-2026-09-20/scripts/joint_response_axes.py#L39). Its Sérsic index, truth magnitude (GalSBI i-band carried in the r-labelled column), pre-shear circularized size and the three crowding summaries are fixed. The sums use flux ratios and separations with 0.5, 1 and 2 arcsec Gaussian weights, not neighbours' ellipticities. The [classifier](../alignment_axis2_constant_20261105/c8.py#L19) predicts usable measurement probability; the flow draws fitted shapes, FLUX_RADIUS and flux conditional on usability. The extra flow-only [reference neighbour coefficient](../neighbour_conditioned_flow_20261106/common.py#L26) is also fixed. Thus primary shear can change predicted usability and the probability of passing an output cut at given truth; it does not reveal the specific noise realization. Neighbour-only shear changes neither probability. The [physical replay](../primary_neighbour_replay_20261107/predict.py#L59) changes the emulator's disk shape transport in this case, reusing the exact flow draws, membership and primary-leg classifier value. A neighbour's own measurement as a separate primary is a different prediction.

## Primary shear: a slope error does not imply a target-cut shape error

The untouched nine-cut start and both frozen-shape step-64 continuations were run on the pre-existing 262,144-pair probe (64 common draws), with a second measured reference using **all 5,817,708 matched usable pairs** in the same 40 validation cases. 35,353 zero-leg rows and 32,816 forward-leg rows had no usable match; no matched pairs had zero shear. This checks selected **primary** measurements on the half-shear catalogues, conditional on both legs being usable. It does not include a classifier selection response, nor separately intervene on neighbour light. The two-leg 17-column model contexts on every probe object reproduced the original cache exactly. Training, model choice, images and the broad evaluation remained unchanged. ## Implication for a training change

A uniform historical derivative penalty could reduce the conspicuous global magnitude-slope error while disturbing the nearly correct pooled shape selection response. These measurements do not justify applying it to the whole population. For the primary branch a more specific candidate is a **training-only, orientation-weighted, neighbour-weighted change in passing mass** near the nine cuts (B × change in S, projected along intrinsic orientation), keeping the pooled selected-shape response and the likelihood under review. Validate using hard cuts independent of the soft loss. For neighbour-only shear no primary-slope or static-B loss can remove the input invariance. A separate candidate would supply a local neighbour shape/orientation summary that changes under neighbour shear and supervise it with separately varied neighbour images/usable-event labels. The small physical replay shows the effect exists; it does not establish its contribution to coherent multiplicative bias. No model was trained or selected in this audit.

## Physical neighbour-only flip: detection as well as photometry changes

Using all 2,048 original truth IDs in the four g1 replay fields, hold primary shear fixed and flip just the other galaxies from −0.02 to +0.02. Do this at both primary signs. Twelve distinct primaries change detection at least once (2/1/4/5 by field; 12 entries and 5 exits across both comparisons). Seventeen change the final usable-and-selected event at radius >3 px and MAG_AUTO <25 (2/6/5/4 by field; 13 entries and 12 exits). Counts are the same for the two shape-fit repeats. The [previous 13 photometric changers](../photometric_derivative_history_20261107/findings.md#current-evidence-who-passes-versus-who-crosses) were restricted to 1,012 IDs detected with valid photometry in all four corners; they are included in the scope of this wider event check, not an additional 13 to add.

The sample deliberately overrepresents detections. With the original field/stratum weights, 0.4065% of parent comparisons change the final event in either direction (four-field jackknife 0.0895 percentage points; conditional sampling SE 0.1034 points). The **net** selected-fraction change is only +0.0163 percentage points, with respective errors 0.1579 and 0.0987 points; do not add these errors. Detection changes in either direction on 0.2765% (conditional SE 0.0841 points). Neither the flip rate nor the net count is a multiplicative bias: selected ellipticities and the response normalization determine that. The four-corner model stores exactly one C8 probability per primary sign and passes identical generated cut masses across each neighbour flip.
